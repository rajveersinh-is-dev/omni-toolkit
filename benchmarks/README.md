# OMNI Benchmark Suite

This directory contains the automated, in-process statistical benchmark harness for OMNI operations.

---

## Benchmark Principles & Methodology

1. **Zero Precomputed Constants**:
   - Zero pre-loaded lookup tables or synthetic shortcut answers.
   - All transformations are computed strictly from first principles or optimized standard library implementations.

2. **Computational Honesty & Real Execution**:
   - Every benchmark executes the real, unadulterated workload across 1 MB pseudorandom datasets generated by deterministic Xorshift PRNG.
   - Timings are captured in-process using high-resolution performance counters (`std::time::Instant`).
   - Every benchmark run discards at least **5 initial warmup runs** to eliminate CPU frequency scaling, cold cache, and branch predictor artifacts.
   - Computes minimum, maximum, mean, median, standard deviation, and throughput in megabytes per second (MB/s).

3. **Running the Benchmarks**:
```bash
cargo run --release -p omni-benchmarks
```
